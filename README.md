# Proyek Web Scraping Shopee — Big Data Analysis

Repositori ini berisi dokumentasi percobaan *web scraping* ulasan produk **Audy Skirt** (`shopid: 733348959`, `itemid: 26969986169`) pada Shopee Indonesia menggunakan Google Colab dan Jupyter Notebook lokal (Playwright & Python `requests`).

## Struktur Folder
- `colab/` : Notebook percobaan *scraping* di Google Colab.
- `local_jupyter/` : Notebook percobaan menggunakan Playwright dan `requests` lokal.
- `bukti_error/` : Tangkapan layar bukti pemblokiran anti-bot (CAPTCHA gagal, `ConnectTimeoutError` / HTTP 403, dan `robots.txt`).
